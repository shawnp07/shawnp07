## About
When I started learning computer science in high school, I had the opportunity to make the lives of each class of students there a little easier. In collaboration with 3 other students, I created an interactive map that would help them find the correct rooms. This app included an algorithm to find a path from the entrance to any room on the school's 4 floors. The device that runs the program was installed at the end of the semester. It was challenging, but we felt proud that our idea to help the school worked out.

I am now learning lower-level programming languages such as C at University of Illinois Chicago. The higher-level tools that I used in high school, such as Python, Java, and React, are still skills I want to refine. I am endeavoring to bring my skills in software engineering to Chicago.
